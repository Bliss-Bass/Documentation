# BlissDeck

> **Android 16 Lineout.** Screenshots and steps on these pages were taken on **Bass: Lineout** (Lineage **23.2** / Android **16**). On **Android 14** (Lineage **21.0**) the same tools can look different, sit in a different Settings place, or be missing from that image entirely.

BlissDeck is a **landscape game-library Home screen** for Bass gaming images. It lists installed games and apps, can fetch cover art, and is meant to stay on the TV or tablet in landscape.

## What it is for

On gaming images, BlissDeck is installed on first boot and becomes the Home app when the device starts in Gaming mode. You should not need to tap through accessibility or usage-access prompts.

## How to use it

1. After first boot, the Home key (or the Windows key) opens BlissDeck.
2. Browse **Recents**, **Library**, and **Settings** inside the app.
3. Optional: add a SteamGridDB API key in BlissDeck **Settings** for cover art.

If you do not see BlissDeck, this image was built without it, or you started the device in Tablet, Desktop, or Kiosk mode instead of Gaming.
